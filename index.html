Slide 8

Change One Paragraph

JavaScript selects the button and paragraph. The event listener waits for a click. When the click happens, the handler changes the paragraph’s text.

Try it: Click “Show today’s special” and watch the paragraph.

Choose a special.

  • Selected elements: the button receives the action; the paragraph receives the new text.
  • Click event: the listener waits until the button is activated.
  • Visible update: textContent changes the words without reloading.
Show code

Prepared HTML

<button id="specialButton" type="button">
  Show today’s special
</button>

<p id="specialMessage" role="status">
  Choose a special.
</p>

JavaScript being taught · js/demo-click.js

// These IDs connect this JavaScript to the button and paragraph in index.html.
const button = document.querySelector('#specialButton');
const message = document.querySelector('#specialMessage');

// Wait for the HTML button to be clicked, then replace the paragraph's words.
// Its appearance stays controlled by CSS; JavaScript changes only the text.
button.addEventListener('click', function () {
  message.textContent = 'Tomato soup';
});

Slide 13

Change a Style While Typing

The input event runs when the field changes. JavaScript reads the current value and decides whether the paragraph should have a CSS class. The CSS defines how that class looks.

Try it: Type a name, then delete every character and compare the paragraph’s style.

Your greeting preview

Class absent: the field is empty.

The has-name class is present when the field contains any characters, including spaces. The words in the paragraph stay the same.

Show code

Prepared HTML

<label for="guestName">Your name</label>
<input id="guestName" type="text">

<p id="greeting">Your greeting preview</p>

Prepared CSS · two states

#greeting {
  padding: 1rem;
  border: 2px solid #526c7b;
}

#greeting.has-name {
  background: #d9f4e8;
  border-color: #006e60;
}

JavaScript being taught · js/demo-styling.js

// These IDs connect this JavaScript to the input and preview paragraph in index.html.
const nameInput = document.querySelector('#guestName');
const greeting = document.querySelector('#greeting');

// Check the field whenever its text changes; CSS uses the class to change the paragraph's look.
nameInput.addEventListener('input', function () {
  const hasText = nameInput.value !== '';
  // Add the CSS class when there are characters; remove it when the field is empty.
  greeting.classList.toggle('has-name', hasText);
});

Slide 19

One Error Appears and Clears

The condition checks whether the name is empty after surrounding spaces are ignored. An empty value gets an explanation. A useful value clears that explanation and the invalid state.

Try it: Check an empty name, then type a name to clear the error.

This demo checks a name. It does not send a message.

trim() ignores surrounding spaces here. A spaces-only name is empty for this check. Correcting the name clears the error as you type.

Show code

JavaScript being taught · the seven-line decision

// Put an error in the HTML message and mark the field for its invalid CSS style.
if (field.value.trim() === '') {
  error.textContent = 'Enter your name.';
  field.setAttribute('aria-invalid', 'true');
} else {
  error.textContent = '';
  field.setAttribute('aria-invalid', 'false');
}

Full setup

Event listeners and local submit · js/demo-validation.js

// These IDs connect the form, field, error message, and status message in index.html.
const field = document.querySelector('#name');
const error = document.querySelector('#nameError');
const form = document.querySelector('#nameForm');
const formStatus = document.querySelector('#formStatus');

// Recheck the field as the learner types and clear any old submit message.
field.addEventListener('input', function () {
  formStatus.textContent = '';

  // Ignore spaces at the ends. The error text appears in #nameError; CSS hides
  // it when empty, and styles the input when aria-invalid is true.
  if (field.value.trim() === '') {
    error.textContent = 'Enter your name.';
    field.setAttribute('aria-invalid', 'true');
  } else {
    error.textContent = '';
    field.setAttribute('aria-invalid', 'false');
  }
});

// Handle the HTML form's submit event so this local classroom demo does not navigate away.
form.addEventListener('submit', function (event) {
  event.preventDefault();
  formStatus.textContent = '';

  // A bad submission shows the same error and puts the cursor back in the field.
  if (field.value.trim() === '') {
    error.textContent = 'Enter your name.';
    field.setAttribute('aria-invalid', 'true');
    field.focus();
  } else {
    // A good submission clears the error and reports the result without sending data.
    error.textContent = '';
    field.setAttribute('aria-invalid', 'false');
    formStatus.textContent = 'Name checked. Demo only: nothing sent.';
  }
});
